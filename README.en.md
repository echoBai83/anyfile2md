# anyfile2md — anything to Markdown

Drag and drop office documents, e-books or images onto a script — get clean Markdown back.

Lazy-loaded, one process per run, **no background service**.

```
PDF / Word / PPT / HTML / EPUB / Excel / CSV / images  →  .md
```

## What it supports

| Input | Engine | Notes |
|---|---|---|
| **PDF** | PyMuPDF4LLM | Main feature; scanned PDFs can use OCR |
| **Word (.docx)** | pandoc | Headings, lists and tables preserved |
| **PowerPoint (.pptx)** | pandoc | Text and outline structure |
| **HTML (.html / .htm)** | pandoc | Links and tables preserved |
| **E-books** EPUB / MOBI / FB2 / CBZ / XPS / SVG | PyMuPDF4LLM / pandoc | |
| **Excel (.xlsx / .xls) / CSV** | pandas | One Markdown table per worksheet |
| **Images** PNG / JPG / TIFF / GIF / BMP / WEBP | tesseract OCR | Chinese (Simplified) + English by default |

> Legacy `.doc` / `.ppt` (Office 2003) are not supported — re-save as `.docx` / `.pptx` first.

## Quick start

Requires **Python 3.10+**.

```bat
:: 1. install Python deps into .\lib (does not touch your global site-packages)
install.bat

:: 2. optional: also download the tesseract OCR engine + chi_sim/eng language data
install.bat --with-tesseract
```

External tools, installed automatically when found:

| Tool | Used for | Install |
|---|---|---|
| **pandoc** | docx / pptx / html conversion and Markdown clean-up | `winget install --id JohnMacFarlane.Pandoc` |
| **tesseract** | OCR for images and scanned PDFs | `install.bat --with-tesseract` |

The converter probes `PANDOC` / `TESSERACT` env vars, then a local `pandoc\` / `Tesseract-OCR\` folder,
then `PATH`, then the usual Windows install locations — so no absolute paths are hard-coded and the
folder can live anywhere, including paths with Chinese characters or spaces.

## Usage

**Drag & drop**: drop one or more files onto `markdown_convert.bat`. The `.md` is written next to the
source file, same base name.

**Command line**:

```bat
python converter.py report.pdf
python converter.py a.pdf b.docx c.xlsx
python converter.py a.pdf --outdir D:\out
python converter.py a.pdf --no-clean
python converter.py a.pdf --embed-images
python converter.py scan.png --lang chi_sim+eng
python converter.py a.png --no-ocr
```

`markdown_convert.bat` converts **and** runs the pandoc GFM clean-up;
`markdown_convert_noclean.bat` keeps the raw engine output (handy when debugging formatting).

## Layout

```
├── markdown_convert.bat          drag & drop entry: convert + clean
├── markdown_convert_noclean.bat  drag & drop entry: raw output
├── install.bat                   one-click dependency install / upgrade
├── setup_deps.py                 dependency install + tool probing
├── converter.py                  the converter
├── requirements.txt              pinned versions
├── markdown_convert.ico          icon for your shortcut
├── docs/                         sample files and icon source
├── lib/                          generated by install.bat (git-ignored)
└── Tesseract-OCR/                optional OCR engine (git-ignored)
```

## Low-overhead by design

- One-shot process: exits after converting, zero idle CPU/RAM.
- Lazy imports: only the libraries for the format being converted are loaded.
- OCR only runs for images / scanned PDFs.
- Files are processed and released one at a time.

## Portable build

Don't want to set up dependencies? Grab `anyfile2md-v0.1.0-win64.zip` from the **Releases** page. It
ships `lib/` and `Tesseract-OCR/` pre-bundled, so there is no `pip install` (you still need a Python
3.10+ interpreter on the machine).

Note: **the presence of a local `lib/` switches the program into portable mode** — it then only uses
bundled pandoc / tesseract and ignores anything installed on the system `PATH`. That keeps behaviour
reproducible; use the source build if you want system-wide tool discovery.

### Adding pandoc (.docx / .pptx / .html need it)

pandoc is not bundled (its official exe is 233MB, over GitHub's per-file limit); the Release page ships
it as a **separate asset**:

1. Download [`pandoc-3.8.3-windows-x86_64.zip`](https://github.com/echoBai83/anyfile2md/releases/download/v0.1.0/pandoc-3.8.3-windows-x86_64.zip) (official build, ~39MB)
2. Extract `pandoc.exe` into the portable folder's `pandoc\` directory:
   ```
   anyfile2md-v0.1.0\
   └── pandoc\
       └── pandoc.exe
   ```
3. Run again — it is auto-detected, no configuration needed.

> Not required for PDF / Excel / CSV / images / e-books.
> Alternatively install pandoc system-wide and use the source build instead.
